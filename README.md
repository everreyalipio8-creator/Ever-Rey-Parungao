# Ever Rey Parungao — Portfolio Website

A responsive personal portfolio website inspired by the provided reference video.

## Files
- `index.html` — complete website (HTML, CSS, and a small JavaScript snippet).

## Preview locally
1. Download or extract this project.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository (for example, `ever-rey-parungao-portfolio`).
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The website URL will appear in the Pages section.

You can also import the repository into Vercel to deploy it there.

## Customize before publishing
- Replace the example email address in the Contact Me section.
- Update the About Me text and skills to match your real information.
- Replace the sample project cards with your own projects.
